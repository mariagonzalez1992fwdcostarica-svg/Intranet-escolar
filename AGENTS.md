# Intranet Escolar

## Contexto
Proyecto para desarrollar una intranet escolar que facilite la gestión y la comunicación dentro de la institución educativa. Este sistema servirá como punto de acceso centralizado para la comunidad escolar.

## Requerimientos
- El stack tecnológico exclusivo para este proyecto es **HTML, CSS y JavaScript**. No se utilizarán frameworks adicionales a menos que se especifique lo contrario.
- Interfaz moderna, responsiva y fácil de usar.

## Reglas
- Todo el código debe estar bien documentado y organizado.
- Se deben utilizar nombres semánticos para variables, funciones, clases CSS y etiquetas HTML.
- Fomentar la modularidad y reutilización del código.

## Restricciones
- **OBLIGATORIO:** NO exponer datos personales de menores bajo ninguna circunstancia. La privacidad y seguridad de la información de los estudiantes es prioritaria.
- **OBLIGATORIO:** NO guardar contraseñas en texto plano. Toda contraseña debe ser manejada de forma segura (hasheada/encriptada).

## Objetivos
- Construir una plataforma segura, rápida y accesible para todos los usuarios.
- Mejorar el flujo de información entre administradores, profesores, alumnos y padres.

## Memoria del Proyecto
- En esta sección se registrará el progreso del proyecto, las decisiones técnicas importantes tomadas durante el desarrollo y los cambios de arquitectura relevantes.

## Buenas Prácticas
- Aplicar principios de diseño responsivo (Mobile First).
- Optimizar recursos (imágenes, scripts) para garantizar tiempos de carga rápidos.
- Asegurar la accesibilidad web (cumplimiento de estándares WCAG).
- Implementar validaciones tanto en el lado del cliente como en futuras integraciones de servidor.
