# Intranet Escolar — Sistema de Gestión Académica e Institucional

Bienvenido a la **Intranet Escolar**, un prototipo de aplicación web diseñado para la gestión académica y comunicación de un centro educativo público.

---

## 🚀 Características Principales

- **Autenticación Accesible por Roles:** Vistas adaptadas para Administradores, Personal Docente y Estudiantes/Familias.
- **Gestión Académica:** Consulta de calificaciones y porcentajes de asistencia sin exposición de datos personales de menores.
- **Diseño Inclusivo:** Interfaz responsiva que cumple con los principios de accesibilidad web (RNF-01).

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 semántico, CSS3 (Flexbox/Grid, variables) y JavaScript Vanilla (ES6+).
- **Control de Versiones:** Git & GitHub (Flujo de trabajo estructurado por ramas `main` y `feature/*`).
- **Persistencia Local:** LocalStorage para simulación de sesiones.
